# Financial Market Analytics Platform — Frontend

A Next.js and TypeScript dashboard for the Financial Market Analytics Platform.

The frontend provides an interactive interface for analyzing stock market data, technical indicators, and machine learning predictions generated by the backend analytics pipeline.

## Overview

This application is built with:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lightweight Charts

It connects to a FastAPI backend to visualize:

- Historical OHLC market data
- Candlestick charts
- Moving averages
- Technical indicators
- ML-based BUY / HOLD / SELL signals

## Features

### Market Visualization

- Interactive candlestick charts
- Historical stock price analysis
- Moving average overlays

Supported indicators:

- MA7
- MA20
- MA50
- MA100
- MA200

### Machine Learning Predictions

The dashboard displays predictions generated by backend ML models:

- XGBoost
- Random Forest

Prediction signals:

- BUY
- HOLD
- SELL
