# Financial Market Analytics Platform — Frontend

A Next.js and TypeScript dashboard for the **Financial Market Analytics Platform**.

The frontend provides an interactive interface for analyzing historical market data, technical indicators, market signals, and machine-learning predictions generated by the FastAPI backend.

---

## Overview

The frontend is responsible for the presentation and visualization layer of the platform.

It connects to the backend through REST APIs and WebSocket infrastructure to display:

- Historical OHLC market data
- Interactive candlestick charts
- Moving-average indicators
- Current market price
- Technical market signals
- Machine-learning predictions
- Prediction probabilities
- Prediction confidence
- Model information
- Signal comparison

The dashboard is designed as a production-style financial analytics interface rather than as a standalone trading application.

> **Disclaimer:** Machine-learning predictions are experimental analytical signals and should not be interpreted as financial advice or used as a standalone basis for investment decisions.

## Dashboard Features

### Market Visualization

The dashboard provides interactive visualization of historical market data.

Features include:

- Interactive candlestick price charts
- Historical OHLC data
- Current market price
- Moving-average overlays
- Responsive chart layout
- Symbol selection

### Technical Analysis

The dashboard displays a technical market signal based on the relationship between:

- **MA7** — 7-period moving average
- **MA20** — 20-period moving average

The technical signal is classified as:

| Signal | Interpretation |
|---|---|
| BUY | MA7 is above MA20 |
| SELL | MA7 is below MA20 |
| HOLD | No clear directional signal |

This technical signal provides a simple market-context indicator.

## Machine-Learning Predictions

The dashboard displays predictions generated by the registered machine-learning model for the selected symbol.

Currently supported model types include:

- XGBoost
- Random Forest

The model produces one of three prediction classes:

| Class | Signal | Interpretation |
|---:|---|---|
| 0 | SELL | Bearish |
| 1 | HOLD | Neutral |
| 2 | BUY | Bullish |

The dashboard displays:

- Prediction signal
- Prediction probability
- Confidence score
- Confidence level
- Probability margin
- Prediction class
- Model type
- Model version
- Current market price

---

## Confidence

The dashboard displays the model's calculated confidence score.

Confidence is derived from:

1. The probability assigned to the predicted class.
2. The probability margin between the highest and second-highest class probabilities.

The confidence level is classified as:

| Confidence | Level |
|---:|---|
| 75% or higher | HIGH |
| 50%–74.99% | MEDIUM |
| Below 50% | LOW |

Confidence represents the model's classification confidence. It does **not** represent the probability that an investment will be profitable.
